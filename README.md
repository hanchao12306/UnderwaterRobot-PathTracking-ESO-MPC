# UnderwaterRobot-PathTracking-ESO-MPC

This repository contains the MATLAB simulation code for the paper: 
**"Path Tracking Control for Underactuated AUVs Based on ESO-MPC with Selective Feedforward Compensation"** .

## 📖 Overview
This code simulates the 3-D path tracking control of an underactuated Autonomous Underwater Vehicle (AUV). It compares the proposed ESO-MPC (with selective feedforward compensation) against a Standard MPC and a PID controller under various disturbance conditions.

## 💻 Requirements
* **MATLAB** (Tested on R2024a)
* **Optimization Toolbox** (Required for the `quadprog` function in the MPC controller)

## 📂 File Structure

### 🚀 Main Simulation Scripts (Run these first)
* `test7_3d.m` : Main script for 3-D trajectory tracking (e.g., generating results for Fig. 3 - Fig. 8).
* `test9_track_astar.m` : Main script for tracking the A*+APF planned path.

### 🧠 Core Algorithms
* `los_guidance.m` : Line-of-Sight (LOS) guidance law for desired velocity generation.
* `eso_estimator.m` : Extended State Observer (ESO) for estimating velocities and lumped disturbances.
* `mpc_controller.m` : The proposed MPC with CLF contraction constraint.
* `pid_controller.m` : Baseline PID controller.
* `adaptive_speed.m` : Adaptive surge speed adjustment logic.

### 🛠️ Utility Functions & Models
* `auv_dynamics.m` : 4-DOF AUV kinematic and dynamic model.
* `set_params.m` : Initializes all AUV physical parameters, controller gains, and environmental disturbances.
* `compute_rms_errors.m` : Calculates the 3-D RMS errors (Table 5, Table 7, Table 8).
* `compare_3d.m` & `utils_plot.m` : Functions for 3-D visualization and plotting figures.
* `analyze_path.m` & `step_cal.m` : Path processing and step calculation utilities.

### 💾 Data
* `astar_path.mat` : The pre-planned path generated by the A*+APF algorithm (Reference: Zhang et al., 2026).

## ▶️ How to Run
1. Clone or download this repository.
2. Open MATLAB and navigate to the repository folder.
3. Open `set_params.m` to check or modify simulation parameters.
4. Run `test7_3d.m` or `test9_track_astar.m` to reproduce the simulation results.
